# Solitaire — техническое задание

Минималистичный open-source пасьянс Klondike без рекламы, трекинга и сети.
Один код на Rust для веба (GitHub Pages), десктопа и Android.

Рабочее название: **Solitaire** (финальное имя выберем позже, оно не должно
пересекаться с чужими торговыми марками).

---

## 1. Цели

1. **Чисто.** Никакой рекламы, аналитики, сетевых запросов, аккаунтов, разрешений.
2. **Легко.** Без webview. WASM-сборка < 1.5 МБ (gzip), APK < 8 МБ, мгновенный старт.
3. **Везде.** Веб-демо на GitHub Pages → можно поиграть до скачивания.
   Тот же код собирается под Windows / macOS / Linux / Android.
4. **Красиво.** Минималистичный плоский дизайн, плавные анимации, темы.
5. **Надёжно.** Логика покрыта тестами, прогресс никогда не теряется.

## 2. Не-цели (сейчас не делаем)

- Другие пасьянсы (Spider, FreeCell и т.д.) — архитектура не должна мешать, но не делаем.
- Солвер и «только решаемые раздачи».
- Таймер и учёт времени.
- Локализация — весь интерфейс только на английском.
- Публикация в сторах (Google Play, App Store, F-Droid). Дистрибуция — только GitHub Releases + GitHub Pages.
- iOS-сборка (архитектура не должна её исключать).
- Звук, хаптика, онлайн-функции.

## 3. Правовые рамки (clean-room)

- Правила Klondike — общественное достояние, их реализуем свободно.
- Вдохновляемся *жанром* минималистичных пасьянсов, но **дизайн свой**:
  не копируем название, иконку, ассеты, скриншоты, точные цвета и раскладки
  каких-либо существующих приложений. Никакого чужого кода не смотрим и не используем.
- Все визуальные элементы (карты, масти, иконки) рисуются процедурно в коде
  или создаются нами. Сторонние ассеты — только под свободными лицензиями (OFL, CC0, MIT).
- Лицензия проекта: **MIT OR Apache-2.0** (файлы `LICENSE-MIT`, `LICENSE-APACHE`).
  Этого достаточно, особая лицензия не нужна.

## 4. Стек

| Слой | Выбор | Зачем |
|---|---|---|
| Язык | Rust stable (edition 2024) | |
| Рендер / ввод / окно | `macroquad` 0.4.x | Лёгкий 2D, WASM + десктоп + Android из одного кода |
| Сохранения | `quad-storage` 0.1.x за трейтом `Storage` | localStorage в вебе, файл на остальных |
| Сериализация | `serde` + `nanoserde`/`serde_json` (по совместимости с хранилищем) | |
| RNG | `rand_pcg` (детерминированный, по seed) | Воспроизводимые раздачи |
| Ошибки | `thiserror` в `core` | |
| Шрифт | **Inter** (SIL OFL 1.1), встроен через `include_bytes!`, сабсет Latin | |
| Тесты | `cargo-nextest`, `proptest`, `insta` | |

⚠️ `quad-storage` давно не обновлялся (2021). Поэтому:
- обязательно прячем его за трейт `Storage` в `app`;
- на раннем этапе проверяем, что он работает с macroquad 0.4 в вебе и на Android
  (на Android текущая директория может быть недоступна для записи);
- если не работает — пишем свою реализацию (localStorage через JS-плагин miniquad +
  файл в app data dir на нативе).

### 5.1 `core`
- `#![forbid(unsafe_code)]`, никаких `unwrap`/`expect`/`panic` на пользовательских действиях.
- Не зависит от графики, времени, файловой системы. Только данные и чистые функции.
- Основные типы: `Card { rank, suit }`, `Pile` (stock, waste, 4 foundations, 7 tableau),
  `Game` (состояние + настройки раздачи + счёт), `Move`, `MoveError`.
- `Game::new(seed: u64, draw: DrawMode)` — детерминированная раздача.
- `Game::legal_moves()`, `Game::apply(Move) -> Result<MoveOutcome, MoveError>`.
- `Game::best_move_for(card)` — куда автоматически отправить карту по тапу:
  1. одиночная верхняя карта (waste или tableau) → в foundation, если подходит;
  2. иначе карта со всем, что на ней лежит → в колонку tableau;
     стопку, которая уже занимает всю колонку, в пустую колонку не переносим;
  3. при равенстве — ближайшая подходящая колонка справа от источника (по кругу), для waste — самая левая;
  4. карты в foundation по тапу не двигаются (случайный тап не должен стоить −15).
- Закрытая карта tableau, оказавшаяся сверху после хода, открывается автоматически в том же ходе (+5);
  undo откатывает ход и переворот вместе.
- Счётчик ходов: каждый успешный `Move` (включая сдачу и переворот waste) = +1, undo возвращает прежнее значение.
- Undo/redo: неограниченный стек; undo полностью восстанавливает состояние, включая счёт.
- `Game::can_auto_complete()` — все карты tableau открыты, игра не выиграна и линейный проигрыш побеждает:
  любая подходящая карта (waste, затем tableau слева направо) → foundation, иначе сдать, иначе перевернуть waste.
  Если два переворота подряд прошли без прогресса (возможно в Draw 3) — кнопку не показываем.
  `Game::auto_complete_plan()` возвращает эти ходы для анимации; штрафы за переворот в нём начисляются как обычно.
- `Game::is_won()`.
- `Game::is_stuck()` — «ходов нет»: ни одно состояние, достижимое без прогресса (сдача по кругу, перекладывания,
  ходы в/из foundations), не даёт прогресса. Прогресс — только необратимое: открылась карта, в stock+waste стало
  меньше карт, победа. Перебор ограничен 2000 состояний; за пределом считаем «не тупик» (лучше промолчать,
  чем зря предложить сдаться). Это детектор тупика, а не солвер.
- Состояние сериализуемо (serde) для автосейва. При загрузке сохранение проверяется (`Board::validate`:
  52 уникальные карты, foundations по масти от туза, корректные колонки; плюс все состояния, достижимые через undo).
  Битое сохранение даёт `LoadError`, а не сломанный стол.
- Тасовка — своя (Фишер–Йейтс поверх `Pcg64`), чтобы раздача по seed не менялась при обновлении `rand`.

### 5.2 `app`
- Игровой цикл macroquad, `async fn main`.
- Модули: `layout` (расчёт раскладки стола), `render` (карты, стол, UI),
  `input` (мышь/тач, drag, tap, double-tap), `anim` (твины), `theme`,
  экраны `main_menu` / `settings_screen` / `stats_screen` / `about` (раскладка считается вручную),
  `storage`, `stats`.
- Состояние отображения отделено от состояния игры: `core::Game` — истина,
  `app` только анимирует переходы между состояниями.

## 6. Функциональность

### 6.1 Игра
- Klondike, режимы **Draw 1** и **Draw 3** (выбирается в настройках, применяется к новой игре).
- Перемещение карт:
  - **drag & drop** одной карты или стопки (мышь и тач);
  - **tap** по карте → карта уходит в лучшее место (`best_move_for`); если ходов нет — лёгкое «покачивание»;
  - тап по stock → сдать карту(ы); пустой stock → вернуть waste.
- **Undo / Redo** без ограничений (кнопки + Ctrl+Z / Ctrl+Shift+Z на десктопе).
- **New game**, **Restart this deal** (тот же seed).
- **Auto-complete**: когда все карты открыты, появляется кнопка — карты красиво разлетаются в foundations.
- Экран победы: счёт, «New game».
- **Автосейв** после каждого хода и при сворачивании/закрытии. Запуск продолжает последнюю игру.

### 6.2 Очки (по мотивам классического Windows «Standard»)

| Действие | Очки |
|---|---|
| Waste → Tableau | +5 |
| Waste → Foundation | +10 |
| Tableau → Foundation | +10 |
| Открыть карту в Tableau | +5 |
| Foundation → Tableau | −15 |
| Перевернуть waste в stock (Draw 1) | −100 |
| Перевернуть waste в stock (Draw 3) | −20 |

- Переворачивать waste в stock можно без ограничений; штраф начисляется за каждый переворот.
- Счёт не опускается ниже 0.
- Бонусов за время нет (таймера нет).
- Undo откатывает счёт к состоянию до хода (без дополнительного штрафа).
- Таблица очков — константы в `core`, покрыты тестами.

### 6.3 Статистика (только локально)
- Хранится запись о каждой завершённой/брошенной игре: `{ date, draw_mode, score, won, moves }`.
  Храним последние 200 игр.
- Экран Statistics:
  - сыграно / побед / % побед (раздельно для Draw 1 и Draw 3 + всего);
  - лучший счёт;
  - текущая и лучшая серия побед;
  - история: список последних игр (дата, режим, счёт, win/loss) + простой график счёта по последним играм.
- Кнопка «Reset statistics» с подтверждением.
- Никакой телеметрии, никаких сетевых запросов.

### 6.4 Настройки
- Draw: 1 / 3.
- Theme: см. 7.2.
- Four-color suits: on/off.
- Animation speed: Off / Fast / Normal.
- Tap to move: on/off.
- Left-handed layout: stock/waste справа ↔ слева.
- Large cards: on/off (см. доступность).
- Reset statistics.
- About: версия, лицензия, ссылка на GitHub, лицензия шрифта.

## 7. Дизайн

### 7.1 Принципы
- Плоско и чисто: без текстур, без «картинок» на картах, без теней (максимум едва заметная).
- Карта: скруглённый прямоугольник, крупный ранг + масть в левом верхнем углу,
  крупная масть по центру. Ранг и масть читаются даже на узкой карте телефона.
- Масти — векторные фигуры, нарисованные кодом (не символы шрифта).
- Рубашка — однотонная с акцентом темы.
- Пустые слоты — тонкий контур/полупрозрачная заливка.
- Иконки кнопок (undo, redo, new, settings, stats) — простые векторы кодом.
- Минимум хрома: стол занимает почти весь экран, панель кнопок компактная.

### 7.2 Темы
Тема — структура цветов (`table`, `card_face`, `card_back`, `ink_red`, `ink_black`,
`ink_blue`/`ink_green` для 4 цветов, `accent`, `slot`, `ui_bg`, `ui_text`).
Стартовый набор (палитры придумываем свои):
- **Light**
- **Dark**
- **Black** (OLED, чистый чёрный стол)
- **Warm** (тёплая бумажная)
- **High contrast** (для доступности)

Переключение мгновенное, с плавным кроссфейдом цветов.

### 7.3 Анимации
- Перемещение карт: твин позиции с easing (ease-out cubic), ~150–250 мс в Normal.
- Переворот карты: «сжатие по X» + смена лица.
- Сдача из stock, возврат waste, раздача в начале новой игры.
- Auto-complete: каскад карт в foundations.
- Неверный ход: короткое горизонтальное покачивание.
- Победа: ненавязчивая анимация (например, волна по картам foundations).
- Animation speed = Off → все переходы мгновенные.
- Анимации не блокируют ввод: новый ход завершает текущие твины мгновенно.

### 7.3.1 Стол (решения M2)
- Stock — в правом верхнем углу, waste — слева от него (в Draw 3 веер из трёх карт вправо), foundations — слева.
  Зеркальная раскладка для левшей — настройка M3.
- Карта: высота = 1.4 ширины, ширина ≤ 140 логических px. Шаг в tableau: закрытые 0.12, открытые 0.28 высоты карты.
- Drag: от 8 логических px движения; стопка падает на стопку с наибольшим перекрытием, которая её принимает,
  иначе возвращается на место. Тап по stock — сдать или перевернуть waste.
- Тулбар: счёт, ходы (или «No moves left»), кнопки New / Undo / Redo и Auto (только когда доступен).
- После победы стол «замораживается», панель с кнопкой New game.

### 7.4 Адаптивность
- Раскладка стола считается из `screen_width/height` каждый кадр (кэшировать при неизменном размере).
- **Портрет** (телефон): 7 колонок на всю ширину, панель кнопок снизу.
- **Ландшафт / десктоп**: стол по центру с ограничением максимальной ширины карты, панель сверху или сбоку.
- Ширина карты = min(по ширине экрана для 7 колонок, по высоте экрана).
- Вертикальный шаг в tableau сжимается, если колонка не помещается по высоте.
- HiDPI: `high_dpi: true`, текст растеризуется с учётом `screen_dpi_scale()`.
- Safe area (вырезы телефонов): настраиваемые отступы, по умолчанию разумный запас сверху/снизу на мобильных.
- Служебные экраны — колонка 360 по центру, раскладка считается вручную (taffy убран на M6).
- Проверочные размеры: 360×640, 390×844, 768×1024, 1280×720, 1920×1080, 2560×1440, + ресайз окна на лету.

### 7.5 Решения M3
- Темы — свои палитры; тест держит контраст мастей и текста по WCAG AA (High contrast — AAA) на всех фонах.
  Тема по умолчанию — Dark (её цвет стола совпадает с фоном страницы до первого кадра). Смена — кроссфейд 0.3 с.
- Анимации: перемещение 200 мс (Normal) / 110 мс (Fast), остальные масштабируются от него;
  раздача — каскад из stock, auto-complete — от младших карт, неверный тап — покачивание, победа — затухающая
  волна по foundations. Off — всё мгновенно. Новый ход мгновенно завершает идущие анимации; перетаскивание — нет.
- Tap to move выключен → карта переносится двойным тапом (≤ 0.4 с); перетаскивание работает всегда.
- Шрифт Inter Regular + SemiBold, сабсет Basic Latin (по 17 КБ), команда сабсета в `assets/fonts/README.md`.
- Иконки (undo, redo, new, auto, settings) — векторы кодом. Кнопка статистики появится на M4.
- Экран настроек на taffy; строки переносятся на узких экранах, на низких — прокрутка перетаскиванием.
  До M4 настройки живут в памяти; «Reset statistics» показана неактивной. About: версия, лицензия,
  адрес репозитория текстом (miniquad не умеет открывать ссылки), лицензия шрифта.
- `prefers-reduced-motion` переносится на M4 (нужен JS-мост, решаем вместе с хранилищем).

### 7.6 Решения M4
- `quad-storage` не подошёл: на нативе пишет `local.data` в текущую папку и паникует (`unwrap`) при ошибке записи
  или битом файле, запись не атомарна; веб-часть рассчитана на miniquad 0.3. Своё хранилище за трейтом `Storage`:
  - веб — `localStorage` через JS-плагин `web/storage.js` и крейт `solitaire-web-bridge` (единственный с `unsafe`,
    ~40 строк FFI; `core` и `app` остаются `forbid(unsafe_code)`);
  - натив — JSON-файл на ключ, атомарная запись (временный файл + rename) в папке данных платформы
    (XDG / Application Support / %APPDATA%; Android — `/data/data/<package>/files`, пакет из `/proc/self/cmdline`).
- Ключи `solitaire/v1/{game,settings,stats}`. Битая запись копируется в `<key>.bad` и считается отсутствующей.
- Автосейв после каждого изменения партии и настроек; ошибка записи не роняет игру, в тулбаре — «Not saved».
- `prefers-reduced-motion` учитывается при первом запуске (пока нет сохранённых настроек).
- Статистика: счётчики по Draw 1 / Draw 3 / всего, лучший счёт и серии хранятся отдельно от истории
  (последние 200 игр), поэтому не «забываются». Дата — UTC. Брошенная партия = New/Restart после ≥ 1 хода.
  После победы Undo/Redo выключены, победа записывается один раз.
- Меню: вкладки Stats / Settings (кнопка в тулбаре). В Settings — «Restart» текущей раздачи и «Reset»
  статистики с подтверждением повторным тапом в течение 3 с.

### 7.7 Новый облик (M6)
Направление — плоский минимализм «фон + акцент», дизайн свой (§3): свои палитры, пропорции и иконки,
ничего не сверяем с чужими скриншотами.
- **Тема = два цвета** `bg` и `accent`; остальные токены (`face`, `slot`, `text`, `ink`, `red`, `blue`, `green`,
  `muted`, `line`, `track`, `disabled`, `on`) выводятся функцией. Цвет, которому нужен контраст, сдвигается
  к белому/чёрному, пока не наберёт порог (текст и масти — AA, High contrast — AAA, рамки — 3:1).
  Красные масти, рубашки и плашки — в цвете акцента темы. Сырые цвета живут только в `theme.rs`.
- **Темы (8):** Dark (по умолчанию, совпадает с фоном страницы), Light, Black, Warm, Ocean, Plum, Moss,
  High contrast. Старые сохранения читаются (имена прежних тем не меняются).
- **Стол:** шапка (меню · счёт · палитра) сверху, три кнопки (новая игра · undo · redo) снизу, стол между ними.
  Закрытые карты в колонке — одна плашка цвета акцента с числом карт (настройка «Show card count»).
  Карта без рамки и тени; опция «Separated cards» даёт едва заметную тень.
  Решения шага 3: шапка 56 и нижняя панель 72 логических px, между ними стол и полоса 56 под кнопку «Finish»
  (auto-complete, появляется только когда доступен). Плашка = 0.08 + 0.09·n высоты карты, зазор до открытых 0.11;
  при раздаче карты летят целиком и «вливаются» в плашку. Счёт и ходы — по центру шапки.
- **Палитра тем (шаг 4):** кнопка-палитра справа в шапке; капсула вырастает из неё за 0.3 с (ease-out, Off —
  мгновенно). Свотч — круг фона темы с точкой акцента, текущая тема — кольцо акцента. Тап по свотчу сразу
  применяет тему (кроссфейд), палитра остаётся открытой; повторный тап по кнопке или тап вне капсулы закрывает её
  и до карт не доходит. Зоны свотчей 44 px (§8), поэтому на узкой шапке ряд прокручивается перетаскиванием и
  уходит под кнопку. Пока палитра открыта, меню и счёт скрыты.
- **Диалог «Start new game?» (шаг 5):** спрашивает только если в партии были ходы и она не выиграна
  (кнопка и клавиша N); иначе новая раздача сразу. Cancel, тап мимо панели или перетаскивание — отмена,
  тап до стола не доходит. Появляется за 0.25 с с подъёмом на 15 px; стол и нижняя панель тускнеют до 30 %,
  шапка — нет. Время открытия/закрытия палитры и диалога — общий `Reveal`.
- **Экран меню (шаг 6):** общая с игрой шапка — стрелка «назад» на месте иконки меню, кнопка палитры не
  двигается и не мигает. Колонка 360 по центру: «Menu», селекторы «‹ Draw 1 card / Draw 3 cards ›» и
  «‹ Left hand / Right hand ›» (шеврон на краю скрыт), пилюли Settings / Statistics / About. До шагов 7–8 пилюли
  открывают прежнюю панель на нужной вкладке (About — в конце Settings); Done возвращает в меню.
  Смена Draw при возврате в игру: нетронутая партия пересдаётся сразу, начатая — через диалог; Cancel оставляет
  партию, новый режим — со следующей раздачи. Переходы: старый экран гаснет 0.2 с, новый проявляется 0.3 с;
  «гаснет» = цвета смешиваются с фоном (непрозрачно), ввод сразу идёт новому экрану.
- **Настройки (шаг 7):** отдельный экран с общей шапкой («назад» ведёт в меню), колонка 360 по центру,
  прокрутка перетаскиванием под шапкой. Блок: название, приглушённое описание (перенос по ширине 300),
  контрол под ним — круглый переключатель, селектор «‹ Off / Fast / Normal ›» или пилюля. Порядок:
  Four-colour suits, Animations, Tap to move, Large cards, Show card count, Separated cards, Current deal
  (Restart — пересдать и вернуться в игру), Statistics (Reset — второй тап за 3 с). В конце — About;
  пункт About в меню открывает этот экран прокрученным до конца. Draw и рука — только в меню, тема — в палитре.
  Панель со вкладками до шага 8 показывает лишь статистику.
- **Статистика и About (шаг 8):** у каждого свой экран с общей шапкой. Статистика: селектор
  «‹ All games / Draw 1 card / Draw 3 cards ›» для трёх чисел (Played, Won, Win rate); лучший счёт и серии —
  по всем играм; «Last 30 games» — столбики (победы акцентом, поражения цветом рамок); «Recent games» —
  последние до 20 партий (дата UTC, режим, счёт, итог), список длиной в число сыгранных; без игр — «No games yet».
  About — версия, лицензия, адрес репозитория, лицензия шрифта. Каждый экран открывается сверху.
  Старая панель со вкладками и `taffy` удалены: WASM 262 → 229 КБ gzip.
- **Адаптив, мышь, клавиатура (шаг 9):** при ширине окна ≥ 1024 весь интерфейс крупнее в 1.15 раза —
  приложение считает раскладку в «виртуальных» пикселях (окно / 1.15), рендер масштабирует одной камерой,
  текст растеризуется под итоговый размер. Esc закрывает палитру/диалог, затем ведёт назад к игре;
  Ctrl+Y — тоже Redo; Tab / Shift+Tab водят фокус (кольцо акцента 2 px) по элементам текущего экрана,
  Enter нажимает, фокус прокручивает список к себе, касание/клик фокус прячет. Hover — та же подсветка
  нажатия на 20 % и курсор-указатель; после первого касания экрана hover отключается. Колесо мыши
  прокручивает настройки и статистику. Удержание Undo/Redo с повтором не делаем.
- **Веб:** canvas запрашивается непрозрачным (`alpha: false` в `boot.js`), иначе всё полупрозрачное
  (тени, вспышки, затемнение) выглядит светлее, чем должно.
- **Компоненты:** кнопка-пилюля, иконка-кнопка, круглый переключатель, селектор «‹ значение ›», диалог без
  затемняющей подложки (фон тускнеет). Нажатие — вспышка акцента, гаснущая за 0.3 с; hover — то же, слабее.
- **Экраны:** Игра, палитра тем в шапке, диалог «Start new game?» (если в партии были ходы), Меню
  (Draw, рука, Settings / Statistics / About), Настройки, Статистика, About. Магазина, рекламы и других режимов счёта нет.
- **Адаптив:** служебные экраны — колонка 360 по центру, на ширине ≥ 1024 — UI-scale 1.15; шапка и кнопки
  привязаны к контентной зоне `max(ширина стола, 360)`. Esc — назад/закрыть, видимый фокус клавиатуры.

## 8. Доступность
Canvas недоступен скринридерам, поэтому делаем то, что реально помогает:
- **High contrast** тема.
- **Four-color suits** (♠ чёрный, ♥ красный, ♦ синий, ♣ зелёный) — для дальтоников и мелких экранов.
- **Large cards**: крупнее ранг/масть, плотнее раскладка.
- **Tap to move**: можно играть вообще без перетаскивания.
- **Animation speed Off** (+ в вебе уважаем `prefers-reduced-motion` по умолчанию, если доступно).
- Крупные зоны нажатия (≥ 44 px логических) для всех кнопок.
- Клавиатура на десктопе: Ctrl+Z / Ctrl+Shift+Z (или Ctrl+Y), N — новая игра, Space — сдать из stock,
  Esc — назад, Tab / Shift+Tab + Enter — фокус и нажатие любого элемента.

## 9. Платформы и сборка
- **Web**: `wasm32-unknown-unknown`, `wasm-opt -Oz`, `web/index.html` + `gl.js`, деплой на GitHub Pages из `main`.
  - `gl.js` берётся при сборке из крейта `miniquad` той версии, что в `Cargo.lock` (версии JS и Rust всегда совпадают).
    `mq_js_bundle.js` не используем: он тянет плагины `quad_net` (WebSocket/XHR) и audio.
    Нужные JS-плагины (например, `sapp_jsutils` для хранилища) добавляем по одному.
  - «Без сети» гарантируется и браузером: CSP `default-src 'none'`, `connect-src 'self'`, скрипты только свои файлы
    (без inline), `'wasm-unsafe-eval'` для WASM. Тест в `app` проверяет, что CSP не ослаблен.
- **Desktop**: Linux, Windows, macOS бинарники в GitHub Releases.
- **Android**: APK в GitHub Releases (через `cargo-quad-apk` / docker-образ macroquad; исследовать на M5).
- iOS — не сейчас.

## 10. Качество (best practices)
- `rust-toolchain.toml`: stable + rustfmt + clippy + wasm32 target.
- `rustfmt` дефолтный, `cargo fmt --check` в CI.
- Clippy строго через `[workspace.lints]`: `all` + `pedantic` (warn) с точечными allow
  (`cast_*`, `module_name_repetitions`, `missing_*_doc`), `unwrap_used`/`dbg_macro`/`todo` = warn,
  `unsafe_code = "forbid"`. В CI `-D warnings`.
- `cargo-deny`: advisories, лицензии (allow-list: MIT, Apache-2.0, BSD-*, ISC, Zlib, Unicode-*, OFL для ассетов), bans, sources.
  - Сетевые крейты (`reqwest`, `ureq`, `hyper`, `quad-net`, `tokio`) запрещены через `bans.deny`.
  - Advisory без исправления в зависимостях macroquad (RUSTSEC-2025-0035, RUSTSEC-2026-0192) — в `ignore`
    с обоснованием; пересматриваем при каждом обновлении macroquad.
- `cargo-shear` — неиспользуемые зависимости.
- **TDD**: новая логика пишется тестом вперёд — сначала падающий тест (red), затем минимальный код (green),
  затем рефакторинг при зелёных тестах. Относится и к тестируемой части `app` (раскладка, настройки, хранилище).
- Тесты `core`:
  - unit-тесты правил каждого типа хода;
  - `proptest`: 52 уникальные карты всегда; undo∘apply = id; foundations всегда упорядочены; счёт ≥ 0;
  - `insta`: снапшоты раздач по seed;
  - покрытие `core` ≥ 90% (`cargo-llvm-cov`, без тестовых папок);
  - unit-тесты лежат в `crates/*/src/tests/<модуль>.rs` (подключаются через `#[path]`, видят приватное),
    интеграционные — в `crates/*/tests/`.
- `[profile.release]`: `opt-level = "z"` (сравнить с "s"), `lto = true`, `codegen-units = 1`, `panic = "abort"`, `strip = true`.
- `justfile`: `check`, `test`, `run`, `web`, `serve`, `size`.
- GitHub Actions: CI на PR (`just check` + сборка wasm), деплой Pages на push в `main`, релиз на тег `v*`. Кэш `Swatinem/rust-cache`.
- Pre-commit через `lefthook` (fmt + clippy). lefthook — не крейт, ставится бинарником из GitHub Releases.
- Conventional Commits, changelog через `git-cliff`.
- Dependabot для cargo и actions.
